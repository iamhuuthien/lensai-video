Tích hợp iPhone (iOS Shortcuts & PWA)

1. Cài Web App ra Màn hình chính iPhone
Mở trang này bằng Safari → nhấn nút Chia sẻ (Share) → chọn "Thêm vào MH chính" (Add to Home Screen).

2. Gắn vào nút Chia sẻ khi lướt TikTok / Reels (Apple Shortcuts)

  • Mở thẳng Web App và tự động phân tích:
    https://lensai-video.onrender.com/?url=[Đầu vào Phím tắt]
  • Hiện kết quả đè ngay trên màn hình TikTok/Reels:
    Gọi POST tới địa chỉ:
    https://lensai-video.onrender.com/api/shortcut
    Body JSON: {"url": "[Đầu vào Phím tắt]"} → lấy trường plain_text.
